# Sistema de Gestión Institucional - Hogar Madre Teresa (Viale, Entre Ríos)

Sistema integral de gestión sociosanitaria y organización institucional para la residencia gerontológica municipal **"Hogar Madre Teresa"** de la ciudad de **Viale, Entre Ríos, Argentina**, adaptado conforme a las normativas del Ministerio de Salud de Entre Ríos y la Ley Provincial Nº 10.932.

---

## 🚀 Módulos del Sistema
1. **Panel de Gestión Institucional (Dashboard):**
   - Control de meta de vigencia al 100% de VGI y PAI.
   - Semáforo de alertas gerontológicas (vigentes, próximas a vencer y vencidas).
   - Acceso al Dossier Ejecutivo Municipal.
2. **Legajos Únicos de Residentes (LUR):**
   - Fichas individuales con fotografía oficial, admisión, historia clínica y medicación.
   - Organización habitacional exclusiva en dos sectores: **Sector Varones** y **Sector Mujeres**.
   - Evoluciones clínicas e informes sociales con firma digital y sello reglamentario.
3. **Valoración Gerontológica Integral (VGI) & Plan de Atención (PAI):**
   - Calculadoras automáticas en tiempo real: Índice de Barthel, Lawton & Brody, Escala de Tinetti, Cuestionario Pfeiffer, Escala de Yesavage y Escala de Gijón.
   - PAI por áreas con objetivos específicos y frecuencias.
4. **Informes Profesionales (Diarios y Semanales):**
   - Redacción de partes de guardia y reportes semanales por especialidad.
   - Exportación e impresión en formato oficial A4 con membrete municipal y bloque de firma/sello.
5. **Grilla de Recolección de Datos Epidemiológicos:**
   - Base de datos estructurada con filtros dinámicos por sector, nivel de dependencia y obra social.
6. **Diagnóstico Poblacional Anual:**
   - Pirámide etaria, estadísticas funcionales y redacción del informe narrativo epidemiológico.
7. **Plan de Acción 2026, Talleres y Equipo Profesional:**
   - Cronograma semanal con registro rápido de asistencia a talleres.
   - Directorio de profesionales matriculados en la Provincia de Entre Ríos.

## 💻 Ejecución Local

El sistema utiliza tecnologías web estándar (HTML5, Vanilla CSS, JavaScript ES Modules) y un servidor HTTP nativo en Node.js sin dependencias externas pesadas.

```bash
# Iniciar servidor local
npm run dev
# Abrir en el navegador en http://localhost:3000
```
